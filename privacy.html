プライバシーポリシー

砂糖ビジュアライザー(以下「本サービス」)の運営者: 【運営者の名前またはハンドル名】 / 連絡先: 【メールアドレスなど】

1. 写真の扱い

  • 写真を選ぶと、端末の中で縮小(長辺1280px)してから、砂糖の量の推定のために、本サービスのサーバー(Cloudflare Workers)に送ります。
  • サーバーは、その写真を、推定を行う Anthropic 社の API(Claude)に転送します。推定結果を受け取ったら、写真は破棄します。運営者は、写真を保存しません。見ることもありません。
  • Anthropic 社での扱いは、同社の規約とプライバシーポリシーに従います。
  • 人の顔や個人情報が写った写真は、送らないでください。

2. 集める情報

  • 写真以外に、名前・メールアドレス・位置情報などは集めません。アカウント登録もありません。
  • 使いすぎの防止のために、IPアドレスに日付と秘密の文字列を混ぜて変換した値(元のIPアドレスには戻せません)を、利用回数の数え上げにだけ使います。この値は、最長で2日間で消えます。
  • サーバーの運用基盤(Cloudflare、GitHub)が、障害対応などのために、アクセスの記録を取ることがあります。
  • 本サービスは、広告や、行動を追跡する仕組みを使いません。

3. 外部のサービス

  • ページの表示には、Google Fonts(文字のデザインの配信)を使います。このとき、閲覧情報がGoogleに送られます。
  • 公開は GitHub Pages、推定サーバーは Cloudflare Workers、推定は Anthropic API です。

4. 数値について

  • 表示する砂糖の量は、写真の見た目と一般的なレシピから推定した目安で、実際の量とは大きく違うことがあります。
  • 「砂糖」は、ショ糖に限らず、ぶどう糖・果糖・はちみつ・シロップ・果汁などの糖類をまとめて、グラニュー糖(スティック1本3g)に換算したものです。1日の目安25gは、WHOの遊離糖類の目安(大人)にもとづきます。
  • 大人向けの目安です。子どもの摂取量の判断には使えません。
  • 糖質制限や血糖の管理、病気の診断・治療・予防には使えません。食事や健康について心配があるときは、医師や管理栄養士に相談してください。
  • 食べることへの不安が強いときは、無理に使わず、専門の相談先に相談してください。

5. 変更

このポリシーは、必要に応じて変更します。変更後は、このページに掲載します。
